# make-design

확정된 방향(인터뷰 결정 기록 또는 미결 항목)을 받아 **경계와 계약을 정본 설계 문서로
확정**하는 에이전트 스킬. **Claude Code**와 **Codex CLI** 두 런타임을 각각 전용
변형판으로 지원한다.

```
/interview    =  무엇을 왜 만들까 (혹은 만들지 말까)
/make-design  =  어떻게 생겼는가 — 구조·인터페이스·불변 조건을 문서로 확정
/make-plan    =  어떤 순서로 실행할까
```

## 왜 필요한가

설계 없이 코드부터 쓰면 계약이 구현 속에만 존재한다 — 그러면 플랜은 근거 없이 짜이고,
검증(verify)은 대조할 정본이 없어 원리적으로 성립하지 않는다. 이 스킬은 결정을 **문서로
먼저** 확정해 후속 단계 전체(플랜·구현·검증)의 기대값 원천을 만든다.

## 핵심 규칙

- **인터뷰 결정 기록을 계약대로 소비한다** — `## 결정`이 유일한 출발점, `## 선택지`
  (기각 이유)는 재논의 방지, 새 미결은 구현으로 밀지 않고 기록으로 회부. 상태가
  `결정됨`이 아니면 시작하지 않는다.
- **되돌리기 어려운 것 우선** — 타입·스키마·경계·공개 API는 지금, 구현 세부는 나중에.
- **뺀 것에는 재도입 트리거** — 트리거 없는 배제는 영원히 안 보게 된다.
- **필수 절 셋** — 결정 사항(근거) / 의도적 배제 표(+트리거) / 미결. 계약은 타입
  시그니처·스키마로 구체적으로 — 이 절이 곧 `/verify`의 대조 목록 원천이다.
- **결정을 코드로 먼저 내리지 않는다** — 문서 확정 전에 소스를 만지면 이 스킬의 실패다.
- 마무리의 마지막 줄은 **권장 모델 + 다음 명령**(대상 경로 포함) 제안이다.

## 설치

```bash
# Claude Code
/plugin marketplace add jsj9346/agent-skills
/plugin install make-design@jsj9346-skills

# Codex CLI
codex plugin marketplace add jsj9346/agent-skills
codex plugin add make-design@jsj9346-skills
```

## 전제

interview→make-design→make-plan→execute→verify 체인의 설계 단계. 인터뷰 결정 기록이
없어도 대상(문서·미결 절)이 특정되면 단독으로 동작한다. 방향 자체가 미확정이면
`/interview`가 먼저다.
