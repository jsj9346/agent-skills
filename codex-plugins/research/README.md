# research

작업 도중 막힌 질문 하나를 **출처 붙은 답**으로 바꿔 **조사 노트 파일**로 남기는
에이전트 스킬. 외부 자료(공식 문서·라이브러리 소스·논문·웹)와 내부 자료(현재
코드베이스·프로젝트 정본·git 이력)를 모두 다룬다. **Claude Code**와 **Codex CLI**
두 런타임을 각각 전용 변형판으로 지원한다.

```
/interview  =  무엇을 왜 만들까를 정한다
/verify     =  계약대로 됐는지 판정한다
/research   =  그게 사실인가 / 어떻게 동작하나 / 전례가 있나에 근거 붙은 답을 준다
```

## 왜 필요한가

조사는 사이클의 어느 단계에서든 튀어나온다 — 설계 중 "이 라이브러리가 그걸
지원하나", 구현 중 "이 함수가 어디서 어떻게 쓰이나", 논의 중 "전례가 있나". 이걸
대화로 처리하면 두 가지가 유실된다: **조사한 사실 자체**(요약·세션 단절로 사라진다)와
**근거**(결론만 남고 "왜 그렇게 알았지"가 사라진다).

이 스킬은 노트를 조사 **시작 전에** 골격으로 개설하고, 사실 하나를 확인할 때마다
출처·확인 방법·버전을 그 자리에서 기록하며, 중단하더라도 "여기까지 봤다"를 남기고
닫는다. 그리고 **결정하지 않는다** — 발견이 어느 결정에 영향을 주는지까지만 표시하고
선택은 그 단계의 스킬과 사용자에게 넘긴다.

## 핵심 규칙

- **근거가 산출물이다** — `research/R-<slug>.md`. 출처 없는 문장은 노트에 없다.
  `## 답`의 문장마다 확신도(확인됨/추정/미확인)와 근거 번호를 붙인다.
- **출처 우선순위** — 프로젝트 정본 → 코드 실물 → **설치된 라이브러리 소스** →
  공식 문서 → 그 외 웹. 위가 아래를 이긴다. 라이브러리 질문은 lockfile부터 연다.
- **상충은 해소하지 않고 기록한다** — 출처가 다르면 둘 다 버전·일자와 함께 남긴다.
- **결정하지 않는다** — `## 영향`은 "이 답이 X 결정을 바꿀 수 있다"까지. "따라서
  X로 하자"는 쓰지 않는다.
- **스킵 게이트** — 답이 이미 대화·정본·이전 노트에 있거나 도구 호출 1~2회로 끝나면
  파일 없이 그 자리에서 답한다.
- 마무리의 마지막 줄은 **권장 모델 + 다음 명령**(되돌아갈 단계 + 경로) 제안이다.

## 노트 형식

여섯 절: **질문** · **답**(확신도 표시) · **근거**(사실·출처·확인 방법·버전/일자 표) ·
**상충·주의** · **영향**(보고만) · **조사하지 않은 것**. 마지막 절이 노트의 신뢰를
만든다 — "조사했다"의 범위가 정직해야 후속 단계가 이 답에 얼마나 기댈지 정할 수 있다.
